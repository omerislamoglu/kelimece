# Kelimece

Türkçe günlük anagram oyunu. Her gün yeni bir kelime verilir ve oyuncular verilen harfleri kullanarak anlamlı Türkçe kelimeler bulmaya çalışır.

## Teknolojiler

- React + TypeScript
- Vite
- Tailwind CSS

## Kurulum

```bash
npm install
npm run dev
```

## Scriptler

- `npm run dev` — Geliştirme sunucusunu başlatır
- `npm run build` — Üretim için derler
- `npm run lint` — ESLint ile kod kontrolü
- `npm run format` — Prettier ile kod formatlama
- `npm run preview` — Üretim derlemesini önizler
